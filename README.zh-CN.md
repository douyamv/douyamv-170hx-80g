## 8G 与 10G 版本对比

> **优先选择 10G 版本。** 显存子系统是该卡最大的差异点：**带宽最高 1.9 TB/s**
> （5120-bit HBM2e @ 3.0 Gbps）——约为 RTX 4090 的 12 倍。这是该卡在 LLM
> 推理上远超同价位的核心原因：解码速度受限于显存带宽。

| 规格 | CMP 170HX **8G 版** | CMP 170HX **10G 版** |
|---|---|---|
| **显存带宽** | ~1.6 TB/s（4096-bit HBM2e） | **~1.9 TB/s（5120-bit HBM2e @ 3.0 Gbps）** ⭐ |
| 显存容量（出厂） | 8 GB HBM2e | 10 GB HBM2e |
| 显存容量（本项目解锁后） | 可寻址 64 GB | 可寻址 80 GB |
| GPU 核心 | GA100（A100 同芯） | GA100（A100 同芯） |
| SM / Tensor Core | 108 / 432（满 die，可解锁） | 108 / 432（满 die，可解锁） |
| FP32 | ~19.5 TFLOPS（解锁后） | ~19.5 TFLOPS（解锁后） |
| FP16 Tensor | ~77 TFLOPS（解锁后） | ~77 TFLOPS（解锁后） |
| FP16 Tensor（出厂） | ~6.3 TFLOPS（固件阉割） | ~6.3 TFLOPS（固件阉割） |
| NVLink | 无（已禁用） | 无（已禁用） |
| PCIe | 出厂 Gen1 x16 → 解锁 Gen2 | 出厂 Gen1 x16 → 解锁 Gen2 |
| 功耗 | 250 W | 250 W |
| 典型 LLM 用途 | 40G 可用，以上有折叠 | 40G 可用，以上有折叠 |

### 为什么带宽是王道

LLM 推理（token 生成）是典型的显存带宽瓶颈：每生成一个 token 都要把完整
模型权重流过显存子系统。1.9 TB/s 的卡比 1.6 TB/s 的卡喂权重快约 19%，
在大模型（权重超出缓存）上直接转化为约 19% 的 token/s 提升。

本项目的 0001/0002 解锁恢复的是**算力侧**；**显存子系统两个版本从未被
阉割**，但 10G 版的位宽天然更宽——这是硬件差异，软件解锁绕不过去。
**要带宽就选 10G 版。**
