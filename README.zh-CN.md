# douyamv-170hx-80g

[English](README.md)

NVIDIA CMP 170HX 80G 解锁项目的方案编号库。

每个问题一个编号，每条方案五要素：**解决什么错误 / 具体改动 / 验证方法（看哪行日志）/ 依赖 / 踩过的坑**。
编号按实验递进顺序排列，后续方案依赖前置编号。
